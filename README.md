# Dweller

Dweller is a nonpartisan civic app that shows each resident, in every state, how local, state and federal decisions shape their own life: how past laws, rulings and ordinances produced their present situation, and how pending bills, rules, court cases and elections could affect them over the next 24 months.

**Status:** early development, Phase 1 (verifying data sources). Dweller is built for all 50 states; development and testing start in one first test area, then expand.

## Principles
- **Nonpartisan.** Neutral, sourced facts about officials and decisions. No grades or endorsements.
- **Evidence first.** Every impact claim cites a primary source with a date, and separates fact from estimate from forecast.
- **Privacy is non-negotiable.** Every field is optional; users can export and delete everything; data is never sold.

## Build order
1. Verify data sources ← *current*
2. Design the profile and impact model
3. Hand-test impact stories on 10 real decisions and 3 sample residents
4. Clickable prototype
5. Pilot in one city with one partner

Each phase must pass its test before the next begins.

## Data credits
Data will come from public sources, including Congress.gov, the Federal Register, state legislatures and election boards, HUD, and county and city governments. Bill data from LegiScan is used under CC BY 4.0.

**Never commit API keys, tokens or any personal data to this repository.**
